# Crypto-perpetual strategy discovery — 100-source repository scan

## Scope and honesty boundary

This is a discovery catalogue produced from 26 targeted GitHub repository-search queries across crypto futures/perpetual strategies, funding/basis, order flow, liquidations, market making, stat-arb, ML/RL, grid, momentum, mean reversion, and backtesting. It records candidate research sources, not 100 validated engines. Search results can contain duplicate projects, forks, generic bots, incomplete repositories, or spot-only code. Those must be filtered by source inspection before any engine is counted.

The target is **crypto futures/perpetual-native**: funding cash flows, mark/index prices, contract specifications, leverage/margin, liquidation, maker/taker fees, slippage, and next-observable-time execution are required where relevant. Spot-only logic is not automatically eligible.

## Audit protocol for all candidates

Each repository must be inspected at source level and assigned one of: ACCEPT (distinct futures mechanism and enough implementation detail), CONDITIONAL (distinct mechanism but missing data/realistic execution or requires a separate simulator), REJECT (duplicate, spot-only, indicator wrapper, untestable, look-ahead, no source, or no genuine strategy). For every accepted/conditional candidate record the exact mechanism, formulas, source files, market/data requirements, entry/exit, holding horizon, execution model, funding treatment, fees/slippage, liquidation/margin handling, look-ahead controls, validation design, and licence.

Do not count parameter changes, timeframe changes, indicator threshold variations, or cloned repositories as separate mechanisms. One strategy family counts once even if several repositories implement it.

## Mechanism taxonomy to enforce distinctness

1. Directional time-series momentum / trend persistence
2. Cross-sectional momentum / relative strength
3. Breakout / volatility expansion / range compression
4. Mean reversion / volatility-normalized reversion
5. Funding-rate carry / funding extreme fade
6. Futures-spot basis / calendar spread / term-structure carry
7. Cross-exchange funding and price dislocation
8. Liquidation cascade / forced-flow continuation or reversal
9. Open-interest impulse / price-OI divergence / positioning crowding
10. Taker-flow imbalance / volume-clock toxicity / VPIN
11. L1/L2 queue imbalance / microprice / OFI
12. Hawkes event intensity / self- and cross-excitation
13. Market making / inventory control / adverse-selection filters
14. Grid / inventory rebalancing / volatility-adaptive quoting
15. Statistical arbitrage / pairs / cointegration / residual spread
16. Cross-sectional factor portfolio / rank and neutralization
17. Options-implied volatility / skew / gamma and futures hedging
18. On-chain / exchange-flow / miner / stablecoin liquidity factors
19. ML supervised / sequence / regime-conditioned policy
20. Reinforcement learning / dynamic execution and position policy

The taxonomy is a classification scaffold, not a claim that all 20 are independently profitable or even eligible. Several categories contain multiple genuinely different sub-mechanisms; independence is established by the actual causal mechanism, not by the category label.

## Eligibility gate before BTC/ETH futures backtests

- Native BTCUSDT and ETHUSDT perpetual execution model or a justified clean-room port.
- Timestamped feature availability; no same-bar close fills from same-bar signals.
- Fees, slippage, funding settlements, mark/index basis and liquidation/margin rules.
- Out-of-sample / walk-forward splits, regime and year breakdowns, sensitivity to cost stress.
- Sufficient trades and exposure; report zero/low-trade candidates honestly.
- Preserve null results and rejection reasons. No optimizer-selected in-sample result may be described as validated.
